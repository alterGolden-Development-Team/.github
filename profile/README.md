# alterGolden Development Team

A home for personal projects by [alterGolden](https://github.com/alG-N), with invited contributors helping along the way. We build Discord bots, automation tools, and experiments driven by things we want to use.

## Projects

| Project | Focus |
| --- | --- |
| Aetheris | Windows automation for Umamusume training on Steam and BlueStacks. |
| ShoukakuBot | A Discord utility bot with music, downloads, integrations, and moderation. |
| UmaClub | A Discord bot for Umamusume fan tracking, leaderboards, and daily reports. |
| [FumoBOT](https://github.com/alterGolden-Development-Team/FumoBOT) | A multipurpose Discord bot with fun commands, economy, and custom features. |
| [Unfair Bossfight](https://github.com/alterGolden-Development-Team/alterGoldenBossfight) | A Roblox game about the most unfair bossfight that ever made! |

Some projects are private and available to invited collaborators.

## Contributing

For public projects, check the repository README and open an issue to discuss a bug or idea before starting a larger change. Pull requests with a clear explanation and relevant checks are welcome.

For private projects, contact alterGolden to discuss contributing. Access is assigned per project.

[Visit altergolden.dev](https://altergolden.dev)
